`axon` is the command-line entry point to a platform run by an organisation.
You install one tool, log in once with `axon login`, and reach the platform
through a command group named for each part of it. The first group is
`axon devenv`, which is your way to the organisation's SkyPilot API server:
dev environments, GPUs, jobs and volumes.

`axon` serves any organisation. What makes it serve yours is an
**organisation file**, which your organisation gives you. It holds the
addresses and names that `axon` needs, and `axon` itself names no
organisation.
